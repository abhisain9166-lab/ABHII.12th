# ABHII.12TH

A responsive static website starter for an RBSE Class 12 study platform.

## Included
- Subject hub
- Topic-wise practice structure
- MCQ demo
- PYQ / sample-paper library placeholders
- Doubt Corner demo form
- Mobile responsive design

## Important
This is the first working website prototype. The PDF/PYQ database and real doubt backend are not included yet. Before publishing educational material, verify the latest RBSE syllabus and use content you have permission to publish.

## Run
Open `index.html` in a browser.

## Publish
Upload these files to any static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages. You will then get a public HTTPS link that can be opened in Google Chrome.
